# Аудит предыдущего прототипа

Предыдущая реализация была использована только как источник форматов и
поведения. В новую архитектуру не переносились её зависимости и composition
root.

Извлечено:

- отчёт `ник / причина / всего-неделя`;
- суффикс `(RW)`;
- список бан-причин FT и базовый список RW;
- формат старых `bans.json`, `history.json`, `queue.json`, `settings.json`;
- разбор chat component и hover `[Подробнее]`;
- отслеживание выхода с проверки;
- offline-доставка Fabric.

Устранено:

- JSON + `fsync` при чтении счётчика из GUI;
- полное перечитывание и перезапись истории;
- синхронная работа с диском и сетью в UI;
- замена корректного `server_mode` ручным переключателем;
- повторное создание всех виджетов истории и причин;
- callback listener до HTTP-ответа;
- heartbeat/pairing и рекурсивный flush Fabric-очереди;
- неограниченный и незащищённый JSONL;
- S3, Discord, сайт, browser/webview и Academy.

Новая цепочка:

```text
Fabric /ban → HTTP validation → bounded queue → один DB worker
            → SQLite WAL/dedupe → узкие Qt signals → нужная панель
```
