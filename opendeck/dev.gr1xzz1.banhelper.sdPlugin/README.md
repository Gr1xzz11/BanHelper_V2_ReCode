# BanHelper AKP153 for OpenDeck

Готовый web-плагин OpenDeck для 15-кнопочного Ajazz AKP153.

## Требования

- BanHelper 2.2.0 или новее должен быть запущен;
- listener BanHelper должен быть включён;
- OpenDeck 2.5.0 или новее;
- установлен device-плагин Ajazz AKP153 / Mirabox HSV293S для OpenDeck.

## Установка

1. Откройте в OpenDeck раздел **Plugins**.
2. Нажмите **Install from file**.
3. Выберите `BanHelper-AKP153.OpenDeckPlugin`.
4. Перетащите действия категории **BanHelper** на отдельную раскладку.
5. Откройте настройки любого действия и нажмите **Проверить**.

По умолчанию используются:

- API: `http://127.0.0.1:8765`;
- токен: `banhelper-local`.

Если listener-порт или токен были изменены в BanHelper, укажите те же значения в настройках действия. Настройки общие для всех 15 кнопок.

## Рекомендуемая раскладка 5 × 3

```text
FT       RW       COPY     OK       SKIP
5.5      LIV      4.3.1    4.3.2    1.11
2.12     4.1      4.6      4.7      4.8
```

Плагин не требует Node.js, Wine или отдельного фонового процесса: он запускается OpenDeck как скрытая HTML-страница и отправляет команды в локальный API BanHelper.
